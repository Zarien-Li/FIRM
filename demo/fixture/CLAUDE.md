# Demo Research Program

- Original program: improve reliable tool-using language models.
- Value metric: successful task completion without invalid state changes.
- Resource boundary: one existing model and one paired development run.
- Deliverable: a load-bearing method contribution, not a benchmark or wrapper.
- The current routing prototype is a candidate realization, not the program.
- One clear paired loss should trigger diagnosis and redesign, not a seed
  sweep or field closure.
